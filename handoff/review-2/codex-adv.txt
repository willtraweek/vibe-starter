2. **[P2] FIXABLE — Both Omarchy installers can install an old binary after successfully building the new one.**  
   [omarchy-app/install.sh:17](/Users/willtraweek/conductor/workspaces/vibe-starter/palembang/template/stacks/omarchy-app/files/scripts/install.sh:17), identically in [omarchy-tui/install.sh:17](/Users/willtraweek/conductor/workspaces/vibe-starter/palembang/template/stacks/omarchy-tui/files/scripts/install.sh:17):

4. **[P2] FIXABLE — `.mts` production modules escape Foldkit’s global coverage gate.**  
   [vitest.config.ts:17](/Users/willtraweek/conductor/workspaces/vibe-starter/palembang/template/stacks/foldkit/files/vitest.config.ts:17):
   > `include: ['src/**/*.ts']`

   TypeScript modules using `.mts` can participate in the application, but this coverage glob excludes them. The independent checker only verifies reported files and declared tier members; `validPath()` also rejects `.mts`, preventing developers from adding them to a tier.
